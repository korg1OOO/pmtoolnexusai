Role-based access control operates at 3 levels:
  1. MEMBERSHIP — WorkspaceRoute/ProgramRoute check if user is a member (any role)
  2. TIER — RequireTier blocks users below minimum subscription tier
  3. PERMISSIONS — RequirePermission blocks unless user has RBAC permission

Key findings:
  • WorkspaceRoute does NOT differentiate admin/manager/member (membership-only)
  • ProgramRoute does NOT differentiate manager/lead/member/viewer (membership-only)
  • All workspace/portfolio/program routes require Business tier
  • /financials requires both Pro tier + budget.view permission
  • Admin panel requires platform admin role
